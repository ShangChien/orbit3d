# 必要的实验与实现约定

这里只保留会影响后续工作的方法和数值经验，不保存已完成问题的逐条修复历史。当前结果见[结果汇总](results.md)，待执行设计见[实验方案](experiments.md)。

## 分子与性质的语义

- **推断图先规范立体标记。** 距离判键可能给非立体键留下E/Z标签；冻结新推断图前清理无效标记，使相同坐标可重复验证。已有图的有效指定立体约束仍须保留并核对。图身份比较要使用一致的序列化表示，不能把显式氢写法变化当成新化学物种。
- **保持已知图。** 结构生成、量化优化、SDF 导出都应保留原子身份、键级、电荷和指定立体信息。重新从距离判键只用于明确需要推断图的输入，不能覆盖用户提供的图。
- **显式氢与立体信息一起比较。** RDKit `RemoveHs` 会保留定义双键立体化学的氢。身份比较采用完整显式氢图，区分“补充原来未指定的立体信息”和“改变已有立体约束”，不通过删除立体信息来制造一致。
- **不同属性不可混名。** HOMO/LUMO 轨道能量不是 ΔSCF IP/EA；垂直 S1−T1 不是绝热能隙；光谱向量不是轨道标签。跨模型按目标名称和单位对齐，不依赖数组顺序。
- **配对使用同一坐标约定。** 原始八叉树轨迹位于网格盒内；无外部Box时，性质评价和SDF导出使用中心化坐标。配对前复用`trajectory_to_instance`，核对原子顺序、变换后的坐标及输入哈希。
- **误差先配对再统计。** 用逐分子预测差与参考差计算 MAE，不能取两个均值之差。所有提案保留分母，联合成功必须逐样本求交。
- **新坐标不继承旧测量标签。** 固定骨架生长等化学变换后的结构只保留原标签的来源信息，不能把原分子的标签当作新分子的真值。

## 训练和梯度

- 某个图的 OCELOT CSV 标签可用于分子级学习；重建构象并不使这个标签成为该精确坐标上的量子测量。无需因此阻塞小分子主实验，但局部性质引导要有单独证据。
- 可微预测与正常推理必须使用同一模型、目标顺序和 scaler。非可微 stacking 使用真实黑盒评价与接受规则，不用另一个平均模型替代。
- MLIP 的力推理路径和性质描述符的坐标可微路径可能不同。对代理做有限差分只能验证 autograd 实现；还需用量子差分或梯度判断是否有物理意义。
- 参数可加载不代表新元素、深度、坐标尺度或条件语义已经学会。迁移显式记录这些变化；新语义需要对应适配训练。
- GRPO 当前只训练 conditioner。若 16 个候选中仅一个成功评价、其余奖励为 −1，标准化优势恒为成功者 `sqrt(15)`、其余 `-1/sqrt(15)`，与正奖励大小无关。这种组不能区分属性优劣；实际出现比例须从完整 rollout 统计，不能凭推理结果猜测。
- 使用某个评价器选择候选或更新模型后，它就不再是该轮实验的独立验证器。多个模型共用标签时，其误差仍可能相关。

## 力、优化和数值

- 保留原始能量、力及失败状态。NaN/Inf 不能变成零受力“平衡态”；更新方向所用的裁剪力不能替代验收的原始力。
- 投影在完整的可动坐标空间定义；固定骨架的反力与可动原子的优化自由度应区分。接受检查必须重新计算完整模型的所有激活目标。
- 接受规则同时相对于当前点和初始点检查，避免逐步累积容差。它能保护指定代理的可行性，不能保证量子目标、收敛到极小点或从不可行起点找到解。
- 物理能量以 float64 报告。严格零容差对数值路径敏感；串行/批量差异和相同路径重放要分别设定、预先记录阈值，不能事后放宽失败条件。
- 独立随机流控制的是随机数消费，不是所有浮点计算。FP32/BF16、batch 划分和注意力后端都可能改变 logits 或采样结果。缓存等价、full-prefix 一致、整条生成轨迹一致是不同验收。
- cached attention 在 query/key 长度不等时需按末端 query 对齐因果 mask；简单复用左上角 causal mask 不成立。只有 profiling 证明收益后才把缓存或批处理优化设为默认。

## 量子计算

- 函数名相近不代表 Hamiltonian 相同。OCELOT调参诊断使用 Libxc 478 的 LC-wPBE；OE62点值验证单独使用PBE0协议。不能把 Gaussian LC-wHPBE、其他 Libxc 变体及不同 ω 调参规则直接视为同一参考。
- def2轨道基组与匹配的标量ECP要一起构造。PySCF 2.12按已知基组名（如`def2-tzvp`）加载ECP，不识别通用名`def2-ecp`。Te/I 的 def2 ECP 扣除 28 个芯电子；仅加载价层基组不等价。旧记录保持当时的 ECP 约定，不能用新默认重标旧结果。
- GPU4PySCF 的版本和自定义 ω 路径需要实际 CPU/GPU交叉验证。全 TDDFT 激发态梯度所需的高阶 XC 导数使用已验证的 CPU Libxc 计算，不能把缺失导数当零，也不能悄悄换成 TDA。
- 梯度对积分网格响应和 SCF 收敛敏感。HI 的初始 1e-9 SCF 测试未通过 1e-5 eV/Å CPU/GPU 力差阈值；单独采用 1e-11 与完整网格响应的 HI/TeH2 检查通过原阈值。这是数值收敛诊断，不改写既有队列协议。[初始检查](experiments/ecp_initial_failure_20261112.json)、[收敛检查](experiments/ecp_tight_grid_20261112.json)
- 固定几何、固定 ω 的局部导数与重新优化几何/重新调 ω 后的性质变化是不同对象。几何优化收敛、图保持和振动极小点也分别验收。

## 环境与产物

Mac 用于代码、CPU 验证和文稿，GPU 计算在远程 Linux 环境。平台挂载的 Docker 存储不作为可随意搬迁的目录；可迁移模型包和实验产物写入持久盘。数据、模型权重、服务器资料不进入 Git。

Torch、DeepMD、GPU4PySCF 等栈按实际验证的组合运行，分开的环境通过带哈希的数值产物交换数据。DeepMD 的 Python PyTorch 后端与启用其 C++ Torch 扩展是不同安装方式。安装和支持范围见[运行说明](runtime.md)。

实验保留足够的配置、权重/输入哈希、原始候选、失败原因和全部导出；整批重放比只验证第一个分子更有意义。研究结果与本地可迁移模型包是不同交付物，数据摘要不等于完整训练重跑环境。

## 硬约束须在 logits 上实施

先做 softmax/top-p 再把禁止元素的概率清零，会使合法但低概率的支持集消失。实机复现中，合法元素原有 4.4e-8 概率质量，float32 累积达到1.000000119，让 `top_p=1` 错误截断合法尾部，后续元素过滤得到全零。元素与电子态 mask 应在指数运算前组合；`top_p=1` 保留完整分布，采样与 GRPO 的策略概率使用同一支持集。不能用重采样、补 null 或跳过整组掩盖该问题。[真实 logits 与原失败策略重放证据](experiments/oe62_sampling_validation_20261112.json)。

`DetermineBonds(allowChargedFragments=True)` 会按价态分配形式电荷；改为 False 则可能分配自由基，不能当作保持闭壳层的简单修复。RDKit sanitize 通过、净电荷为零，均不证明局部电荷类型处于性质模型的训练支持内。生成评价应另报形式电荷分布；不得在看到结果后删掉异常提案并缩小命中分母。[RDKit 接口定义](https://github.com/rdkit/rdkit/blob/master/Code/GraphMol/DetermineBonds/DetermineBonds.h)

已在生成的桥连氧/磷结构上复现通用规范化规则改变总电荷。规范图特征须检查这一守恒条件；不可转换的结构是该Oracle的准入失败，应保留原图、原提案及错误原因。批预测只接收通过特征准入的行，不能把别的电子态预测当作原分子的性质。原图/三维数据不因指纹标准化而改写。

## 生成准入与评价器支持范围

源训练数据最多80原子，不代表生成器永远不会提出更大分子。正式HOMO seed43池出现一个82原子的化学有效提案；Uni-Mol2本轮声明的输入范围为最多80个源原子、共同训练支持不含Te。复评先按这一合同标记不可评价，再批量预测；保留全部提案分母和覆盖率，不能裁剪分子或把缺失预测记作零误差。原化学有效性、原适用域与B的可评价性分别保存。

## 原生坐标与自由提案的判键差异

源三维SFT保留已验证的源图；自由生成只有元素/坐标，需要推断键级和局部形式电荷。两者的图恢复成功率不能默认相同。固定512个原生valid结构中，给定源图均通过，坐标独立判键为502/512，规范化键级/电荷图一致为496/512；0.01 Å细网格后为495/512。10例判键失败均涉及含硝基结构。不能用模板匹配后的源图成功率代替自由提案判键能力，也不能将推断形式电荷等同于DFT原子电荷。[审计](experiments/oe62_source_graph_reconstruction_20261114.json)
